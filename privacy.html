Privacy Policy

Last updated: November 2026

About the Application

Local Gmail Reporting is a privately operated household application that organizes school-related notifications and calendar events.

Google Account Permissions

The application requests Gmail read-only access to retrieve and organize school-related messages. It requests Google Calendar event permissions to create calendar events following user review and approval.

Data Storage and Usage

Retrieved information is processed and stored on a privately managed server for household use. The application does not publish Gmail messages or calendar contents on this website.

Data Sharing

The application is not operated as a commercial service and does not sell personal information. Google API data is used for the application's described functionality.

Data Retention and Deletion

Application data is retained locally as needed for household reporting. The application owner manages deletion of locally stored information. Google account access can be revoked through Google Account settings.

Contact

For questions about this application or its privacy practices, contact the application owner through the contact information provided in the Google OAuth consent screen.
